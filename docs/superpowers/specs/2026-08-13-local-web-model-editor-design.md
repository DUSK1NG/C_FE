# 本地网页模型配置器设计

## 目标

提供一个无需服务器、无需第三方依赖的本地网页，用于创建、编辑、导入和导出二维桁架有限元 `.model` 文件。网页负责输入配置与格式校验，现有 C11 `fem` 程序继续负责求解和结果输出。

## 范围

第一版包含：

- 节点、单元、荷载和约束的表格化编辑。
- 导入已有 `.model` 文件。
- 加载内置三角桁架示例。
- 对 ID、引用关系、数值范围和容量进行即时校验。
- 预览序列化后的 `.model` 文本。
- 下载自定义 `.model` 文件。
- 根据当前模型生成 `fem` 命令行示例。

第一版不包含：

- 浏览器直接执行 `fem.exe`。
- 本地后端服务或网络通信。
- 在网页中显示 TXT、Markdown、CSV 求解结果。
- 修改现有 C 求解器和命令行接口。

## 用户流程

```text
打开 web/index.html
    ↓
新建、加载示例或导入 .model
    ↓
编辑节点、单元、荷载和约束
    ↓
查看即时校验与 .model 预览
    ↓
下载 custom.model
    ↓
使用 fem --input custom.model 执行求解
```

## 页面结构

页面由四个编辑区组成：

1. 节点区：`id`、`x`、`y`。
2. 单元区：`id`、起点节点、终点节点、`E`、`A`。
3. 荷载区：节点、`fx`、`fy`。
4. 约束区：节点、`fix_x`、`fix_y`，下拉值为自由 `0` 或固定 `1`。

顶部提供“新建”“加载示例”“导入文件”“导出 `.model`”操作。底部提供校验消息、文本预览和命令行提示。

## 文件职责

- `web/index.html`：页面语义结构、按钮、表格容器、预览区域。
- `web/styles.css`：响应式布局、表格、错误提示和按钮样式。
- `web/app.js`：模型状态、表格渲染、导入解析、校验、序列化、下载和命令生成。

网页使用原生 HTML、CSS 和 JavaScript，不引入 npm、框架或 CDN 依赖。直接双击 `web/index.html` 即可使用。

## 数据与解析规则

网页生成的文件遵循现有 Stage 8 格式，并保持固定顺序：

```text
NODES
ELEMENTS
LOADS
CONSTRAINTS
```

输入数字采用普通十进制或科学计数法。ID 必须为正整数且在对应区段内唯一。单元引用的两个节点必须存在且不能相同；`E` 和 `A` 必须大于零；约束值只能为 `0` 或 `1`。网页最多允许 10 个节点、20 个单元、10 条荷载和 10 条约束，以匹配当前 C 程序容量。

导入时支持空行和整行 `#` 注释；导出时使用标准空格分隔，并附带简短区段注释。导入错误显示在页面上，不覆盖当前有效模型。

## 校验与错误处理

- 空表格或缺少必填值：阻止导出并定位到对应表格。
- 重复 ID：显示区段和重复值。
- 无效节点引用：显示对应单元、荷载或约束行。
- 数值非法：显示字段级错误。
- 超出容量：阻止继续新增并显示当前上限。
- 导入失败：保留当前模型，显示解析失败原因。
- 没有错误时：清除旧错误，更新预览和命令提示。

## 验收标准

1. 直接打开页面不需要启动服务器或安装依赖。
2. 加载示例后能看到三角桁架的节点、单元、荷载和约束。
3. 新增、编辑和删除一行数据后，预览内容同步更新。
4. 导出的文件能被现有 `read_model_file` 读取，并可交给 `fem` 求解。
5. 导入仓库中的 `triangle.model`、`medium.model` 后，表格数据和再次导出的结构保持一致。
6. 重复 ID、无效引用、非法数值和超容量数据均不能导出。
7. 页面在窄窗口下仍可滚动查看表格，不出现横向布局破坏。
8. 不修改现有 C 源码、测试和 CLI 行为。

## 后续扩展

如果第一版使用顺畅，后续可以单独增加本地后端适配器，用于调用 `fem`、读取结果文件并在网页中展示结果；该扩展不属于本设计的第一版范围。

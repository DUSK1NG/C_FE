# 浏览器端有限元分析设计

## 目标

让本地网页编辑器能够在浏览器内直接分析内置示例和用户上传的 `.model` 文件，并以结果表格、变形示意图和结果柱状图展示计算结果。功能保持纯静态，不启动服务器，不调用本地 `fem.exe`，也不改变现有 C11 命令行行为。

## 用户流程

```text
加载示例 / 上传 .model
        ↓
解析与模型校验
        ↓
点击“开始分析”
        ↓
浏览器端有限元计算
        ↓
显示位移、单元结果、支座反力、平衡汇总
        ↓
显示变形图和结果柱状图
```

上传入口复用现有 `.model` 文件选择器。解析或计算失败时保留当前编辑内容，并在页面状态区显示可定位的中文错误，不渲染不完整结果。

## 方案

采用 JavaScript 复现现有 C11 求解流程，而不是引入 WebAssembly 或后端服务。浏览器端使用现有 `parseModel`、`validateModel` 和模型编辑状态，新增独立的 `analyzeModel(model)` 计算边界；这样既满足离线打开，也能让 Node 测试直接覆盖求解逻辑。

计算流程与 C11 管线保持一致：

1. 将节点 ID 映射为连续节点索引和两个自由度。
2. 根据单元几何计算长度、方向余弦和刚度矩阵。
3. 组装全局刚度矩阵和荷载向量。
4. 根据约束划分自由/约束自由度，求解线性方程组。
5. 计算节点位移、单元伸长/应变/应力/轴力、支座反力和平衡汇总。
6. 对奇异矩阵、零长度单元、非法数值和不稳定模型返回明确错误。

## 结果界面

分析区域位于编辑器下方，默认隐藏，成功分析后显示：

- 节点位移表：节点 ID、X 位移、Y 位移、位移合量。
- 单元结果表：单元 ID、长度、伸长、应变、应力、轴力、状态。
- 支座反力表：节点 ID、X 反力、Y 反力。
- 平衡汇总表：外载荷合力、支座反力合力、残差和最大位移。
- 变形图：原始杆件使用浅色线，变形后杆件使用醒目颜色；按最大位移自动缩放，零位移时保持可见。
- 结果柱状图：按单元显示轴力，正负值使用不同方向；没有单元结果时显示空状态。

图形使用原生 SVG 或 Canvas，不引入第三方图表库。图形只消费分析结果，不参与计算；表格始终是精确数据来源。

## 错误处理和安全边界

- 只有 `validateModel(model)` 通过后才能开始分析。
- 计算前复制模型数据，求解过程不得修改编辑器中的模型对象。
- 所有表格文本使用现有 HTML 转义路径，模型字段不能注入 HTML。
- 文件读取失败、解析失败、校验失败、刚度矩阵奇异和结果非有限值都显示在统一状态区。
- 分析失败时清除旧结果，避免用户误读上一次计算结果。
- 页面明确提示：浏览器端分析是 JavaScript 实现，命令行 `fem` 仍是 C11 参考实现。

## 测试和验收标准

Node 测试必须覆盖：

- 内置三角桁架示例可分析，并得到有限的位移、单元结果和反力。
- 与现有 `tests/data/triangle.model`、`medium.model` 的解析后分析流程成功。
- 修改荷载后结果发生可预测变化。
- 零长度单元、奇异刚度矩阵、非有限结果被拒绝并返回中文错误。
- 上传文件读取后进入同一解析和分析流程，失败时不覆盖当前模型。
- 结果清空、重复分析和空结果状态正确。
- 变形图和柱状图包含结果数据对应的 SVG/Canvas 元素，不依赖第三方库。

验收时运行：

```text
node --check web/app.js
node tests/test_web_model.js
```

并重新执行现有 Stage 1–10、统一管线、输出选择和 CLI C 测试，确认 C11 行为没有回归。

## 非目标

- 不在本次功能中加入服务器、账号、数据库或远程计算。
- 不让浏览器直接启动 `fem.exe`。
- 不改变 `.model` 文件格式、C11 求解器接口或命令行参数。
- 不引入大型前端框架或图表依赖。

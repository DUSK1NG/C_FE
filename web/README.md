# 本地桁架模型编辑器

本地静态网页用于编辑、校验、分析和导出二维桁架 `.model` 文件。分析由浏览器中的 JavaScript 完成，不需要服务器或网络，也不会调用 C 命令行程序。

## 快速开始

从文件管理器打开 `index.html`。选择“加载示例”开始，或导入本地 `.model` 文件。

## 使用

编辑节点、单元、荷载和约束后，查看模型状态与文本预览。模型通过校验后，“开始分析”会显示节点位移、单元结果、支座反力、平衡汇总及图形。导出会下载规范化的 `.model` 文本；浏览器决定下载位置。导入的注释与排版不会保留在导出文件中。

网页分析只显示浏览器中的结果，不会生成求解器的 TXT、Markdown 或 CSV 报告。若要用 C 命令行程序处理导出的模型，请从终端启动已编译的 `fem` 或 `fem.exe`，并通过 `--input` 指向该文件。

## `.model` 格式

文件按以下顺序包含四个分区：

```text
NODES <count>
<id> <x> <y>

ELEMENTS <count>
<id> <node1_id> <node2_id> <E> <A>

LOADS <count>
<node_id> <fx> <fy>

CONSTRAINTS <count>
<node_id> <fix_x> <fix_y>
```

支持空行和以 `#` 开头的整行注释。节点和单元 ID 必须唯一且为正整数；单元引用的节点必须存在，`E` 与 `A` 必须大于零。`fix_x`、`fix_y` 取 `0`（自由）或 `1`（固定）。

网页与 C 求解器都不做单位换算。整个模型必须使用一致单位制，例如 N–mm 制下，坐标用 mm、面积用 mm²、弹性模量用 N/mm²、荷载用 N。

网页容量上限为 10 个节点、20 个单元、10 条荷载和 10 条约束。导入内容超出上限时可以在页面中修正，但校验未通过前不能导出或分析。

## 导入与导出

导入格式错误不会覆盖当前模型，错误会显示在页面状态区。导出前会检查容量、ID、节点引用、数值和约束值；导出始终写出四个分区、统一空行和行尾换行。浏览器管理下载位置和同名文件处理，网页不会修改仓库文件。
